# Paint

[English documentation](README.md)

Локальный редактор для быстрых схем и пометок на скриншотах.

## Запуск

Нужен Node.js 22.12+ (или 24+).

```sh
npm install
npm run dev
```

Открой адрес из терминала (обычно http://127.0.0.1:5173).

```sh
npm run build       # TypeScript + production-сборка в dist/
npm run preview     # просмотр сборки
npm test            # интеграционные тесты в установленном Google Chrome
```

## Возможности первой версии

- Кисть, ластик, линия, стрелка, прямоугольник, овал и текст.
- Ведёрко (G): выбери цвет и нажми внутри области. Заливает связанную область на рисунке или вставленной картинке; замкнутый контур удерживает заливку. Работают отмена и повтор. Заливка хранится поверх исходной картинки, её можно стереть ластиком.
- Ластик от 1 до 512 px, по умолчанию 64 px; размер задаётся ползунком или числом и не меняет толщину кисти.
- «Очистить холст» удаляет все объекты, включая картинки, сохраняя размеры холста. Отмена возвращает всё содержимое.
- При нажатии и перетаскивании объекта рамка выделения сразу показывает его границы.
- Любой участок правого или нижнего края холста, а также ручка в нижнем правом углу меняют область рисования, не масштабируя объекты. Пунктир показывает будущие размеры; Escape отменяет перетаскивание. Удерживай ручку у края окна, чтобы автоматически прокручивать область и расширять холст за пределы экрана. После расширения доступны горизонтальная и вертикальная прокрутка; масштаб остаётся прежним. После изменения работает Undo/redo, а PNG получает новые размеры. Содержимое за уменьшенными границами скрывается и снова появляется при расширении. Ручки доступны с клавиатуры: стрелки — 1 px, Shift+стрелки — 10 px.
- Для прямоугольника и овала: контур, заливка или оба; отдельный цвет заливки. Shift даёт квадрат/круг. Стиль и заливку можно менять у выделенной фигуры.
- Вставка картинки через ⌘V / Ctrl+V, кнопку, открытие файла или drag-and-drop.
- Пустой холст принимает размер первого изображения; большие изображения вписываются в предел 4096 px. Следующие изображения вписываются в текущий холст.
- Выделение (V), перемещение, масштабирование и вращение объектов. Двойной клик по тексту открывает редактирование.
- Цвет, толщина, масштаб холста и кнопка «Вписать холст».
- Отмена/повтор последних 50 действий, включая создание нового холста.
- PNG в исходном разрешении, без выделения и интерфейса; копирование PNG в буфер.
- Автосохранение одного черновика в IndexedDB и восстановление после перезагрузки. Статус сохранения находится внизу.
- Русский и английский интерфейс: переключатель в правом верхнем углу. «Системный» использует основной язык ОС/браузера: `ru` → русский, остальные → английский. Ручной выбор сохраняется между запусками. Язык интерфейса не изменяет подписи на рисунке.

Клавиши: **B** кисть, **E** ластик, **G** ведёрко, **L** линия, **A** стрелка, **R** прямоугольник, **O** овал, **T** текст, **V** выделение. **Shift** при рисовании делает квадрат/круг или фиксирует направление линии шагом 45°. **⌘/Ctrl+Z** отменяет, **⌘/Ctrl+Shift+Z** повторяет, **⌘/Ctrl+S** сохраняет PNG, **Delete/Backspace** удаляет выбранный объект. **Escape** закрывает диалог или отменяет текущую фигуру.

Изображения находятся под пометками. Ластик стирает пометки и сохраняет исходные изображения. Это осознанное поведение для сценария «обвести что-то на скриншоте».

## Стек и данные

React + TypeScript + Vite, Konva/react-konva, idb-keyval для IndexedDB и lucide-react для иконок. Сервер и аккаунт не нужны. Приложение не отправляет картинки по сети. Шрифты системные. Состояние документа содержит изображения и отдельные объекты; это позволяет отменять действия и менять фигуры.

Кнопки доступа к буферу зависят от поддержки API и разрешений браузера. На localhost эти API доступны в поддерживаемых браузерах; для размещённого приложения нужен HTTPS. При запрете кнопки вставки используй ⌘V/Ctrl+V или открытие файла. При запрете копирования сохрани PNG.

Автосохранение привязано к адресу приложения и браузерному профилю. Новый порт или другой браузер не увидит прежний черновик. История отмены не переживает перезагрузку. Очистка данных браузера удалит черновик; для хранения рисунка надолго сохрани PNG. Лимит файла изображения — 30 МБ.

## Приложение для macOS

Готовое **Paint.app** содержит интерфейс и запускается без Node.js, терминала и веб-сервера. Положи его в `~/Applications` или `/Applications`, затем открывай через Finder, Dock или Spotlight (⌘Space → Paint). На рабочем столе можно создать псевдоним приложения.

Для самостоятельной сборки нужны Xcode Command Line Tools и актуальный Rust (не ниже 1.90; если зависимости требуют новее — `rustup update stable`). На этом Mac первая сборка сделана отдельным toolchain, системный Rust не менялся.

```sh
npm install
npm run desktop:dev       # разработка в отдельном окне
npm run desktop:build     # сборка самостоятельного Paint.app
```

Результат: `src-tauri/target/release/bundle/macos/Paint.app`. В desktop-версии вставка/копирование картинок используют системный буфер, а сохранение PNG — стандартный диалог macOS. Веб-версия продолжает использовать браузерные API. Черновик десктоп-приложения хранится отдельно от браузерного.

Текущая сборка рассчитана на Apple Silicon и macOS 12+. Для распространения на других компьютерах может понадобиться подпись Developer ID и notarization; локальный запуск не требует Apple Developer Account.
